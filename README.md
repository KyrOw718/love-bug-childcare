# 🐞 Love Bug Childcare

Boutique daycare website with a hardened, offline-first registration form.

**Live site (after enabling Pages):** https://kyrow718.github.io/love-bug-childcare/

## Highlights
- Single-file, zero-dependency, works fully offline
- Registration form: autosaving drafts (24h expiry), multi-child support, inline validation, age-based program suggestions
- Security: honeypot spam trap, submission throttle, XSS-safe DOM handling, PII auto-purge after submit
- Mobile-first: safe-area insets, 44px+ tap targets, no iOS zoom-on-focus
- Playful-luxury styling: gold-foil headings, hand-drawn SVG ladybug badge, sparkles, confetti

## Enable the live site
1. Repo Settings → Pages
2. Source: Deploy from a branch → main / root
3. Save — live in about a minute
